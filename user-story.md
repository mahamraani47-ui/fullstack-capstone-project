
# User Story

**As a** user
**I want to** give away household items that I no longer need
**So that** other users can find and reuse or recycle them instead of buying new items.

## Acceptance Criteria

* User can view available items.
* User can search for items.
* User can view item details.
* User can register and log in.
* User can add and manage item information.
* User can comment on items.
